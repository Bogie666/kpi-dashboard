SERVICETITAN API REPORT GUIDE
Based on kpi-dashboard project examples

================================================================================
KEY API PATTERNS
================================================================================

1. AUTHENTICATION (OAuth 2.0 Client Credentials Flow)
------------------------------------------------------
Token endpoint:
  https://auth.servicetitan.io/connect/token

Request format:
  payload = f"grant_type=client_credentials&client_id={client_id}&client_secret={client_secret}"
  headers = {"Content-Type": "application/x-www-form-urlencoded"}

Get access token:
  response = requests.post(url, data=payload, headers=headers)
  access_token = response.json()["access_token"]

Key Points:
  - Store credentials in a secrets manager (kpi-dashboard uses Google Secret Manager)
  - Tokens expire, so fetch a fresh one for each request
  - You need both client_id and client_secret


2. REPORT API REQUEST HEADERS
------------------------------------------------------
headers = {
    "Authorization": f"Bearer {access_token}",
    "ST-App-Key": app_key,  # This is separate from client credentials
    "Content-Type": "application/json"
}


3. REPORT ENDPOINT STRUCTURE
------------------------------------------------------
https://api.servicetitan.io/reporting/v2/tenant/{tenant_id}/report-category/{category}/reports/{report_id}/data

Examples from kpi-dashboard:
  - Comfort Advisors: report ID 374338685 (category: technician)
  - Technicians: report ID 374367121 (category: technician)

2. DATE RANGE CALCULATION
------------------------------------------------------
from datetime import datetime, timedelta

today = datetime.now()

# Month-to-Date
from_date = today.replace(day=1).strftime("%Y-%m-%d")
to_date = today.strftime("%Y-%m-%d")

# Year-to-Date
from_date = today.replace(month=1, day=1).strftime("%Y-%m-%d")
to_date = today.strftime("%Y-%m-%d")

# Last Month (complete)
last_month = today.replace(day=1) - timedelta(days=1)
from_date = last_month.replace(day=1).strftime("%Y-%m-%d")
to_date = last_month.strftime("%Y-%m-%d")


3. RESPONSE FORMAT HANDLING
------------------------------------------------------
ServiceTitan can return data in different structures:

# Response can be array or object
records = []
if isinstance(raw_data, list):
    records = raw_data
elif isinstance(raw_data, dict):
    # Check for nested data
    if "data" in raw_data:
        records = raw_data["data"]
    # Can also check for common keys like "rows", "records", "results", "items"


4. DATA CAN BE ARRAYS OR DICTIONARIES
------------------------------------------------------
for record in records:
    if isinstance(record, dict):
        # Dictionary format with named keys
        employee_name = record.get("EmployeeName", "")
        total_sales = record.get("TotalSales", 0)

    elif isinstance(record, list):
        # Array format with positional indices
        employee_name = record[0]  # Position 0 = Employee Name
        total_sales = record[24]   # Position 24 = Total Sales

NOTE: Array indices are specific to each report and can change if ServiceTitan
      modifies the report structure!


5. SAFE DATA CONVERSION
------------------------------------------------------
def safe_int(value, default=0):
    try:
        return int(float(value)) if value is not None else default
    except (ValueError, TypeError):
        return default

def safe_float(value, default=0.0):
    try:
        return float(value) if value is not None else default
    except (ValueError, TypeError):
        return default

def safe_get(data, key, default=None):
    """Safely get value from dict or return default"""
    if isinstance(data, dict):
        return data.get(key, default)
    return default


6. STORE MONEY AS CENTS
------------------------------------------------------
# Convert dollars to cents for storage (avoids floating point issues)
total_sales_cents = safe_int(safe_float(record.get("TotalSales")) * 100)

# When retrieving for display:
total_sales_dollars = total_sales_cents / 100


================================================================================
COMMON GOTCHAS
================================================================================

1. Report IDs are specific to your tenant
   - You need to find yours in the ServiceTitan UI
   - They won't match other organizations' report IDs

2. Parameters vary by report
   - Check the report definition for required parameters
   - Common parameters: From, To, BusinessUnitId, IncludeInactive

3. Business Unit IDs
   - Must be comma-separated strings, not arrays
   - Example: "6540,6534,154684495" (not ["6540", "6534"])

4. Date format must be YYYY-MM-DD
   - Other formats will fail
   - Use .strftime("%Y-%m-%d") to format datetime objects

5. Array indices can change
   - If ServiceTitan modifies a report, array positions can shift
   - Use extensive logging when working with array formats
   - Consider requesting dictionary format if possible

6. Rate limiting
   - ServiceTitan has rate limits (429 status code)
   - Implement retry logic with delays (120+ seconds recommended)

7. Token expiration
   - Access tokens expire
   - Generate a fresh token for each API call or implement refresh logic


================================================================================
FINDING REPORT IDS
================================================================================

To find your report IDs:
1. Open ServiceTitan Reports in your web browser
2. Navigate to the report you want to access via API
3. Right-click on the report and inspect the URL or use browser DevTools
4. Look for the report ID number in network requests

Example URL pattern:
  https://reporting.servicetitan.io/#/reports/374338685

The number at the end (374338685) is your report ID.

COMPLETE EXAMPLE

import requests
from datetime import datetime, timedelta

# 1. Get authentication token
def get_token(client_id, client_secret):
    url = "https://auth.servicetitan.io/connect/token"
    payload = f"grant_type=client_credentials&client_id={client_id}&client_secret={client_secret}"
    headers = {"Content-Type": "application/x-www-form-urlencoded"}
    response = requests.post(url, data=payload, headers=headers)
    response.raise_for_status()
    return response.json()["access_token"]

# 2. Fetch report data
def fetch_report(tenant_id, report_id, client_id, client_secret, app_key, from_date, to_date):
    # Get token
    token = get_token(client_id, client_secret)

    # Set headers
    headers = {
        "Authorization": f"Bearer {token}",
        "ST-App-Key": app_key,
        "Content-Type": "application/json"
    }

    # Build URL
    url = f"https://api.servicetitan.io/reporting/v2/tenant/{tenant_id}/report-category/technician/reports/{report_id}/data"

    # Build payload
    payload = {
        "parameters": [
            {"name": "From", "value": from_date},
            {"name": "To", "value": to_date}
        ]
    }

    # Make request with retry logic
    max_retries = 2
    for attempt in range(max_retries):
        response = requests.post(url, headers=headers, json=payload)

        if response.status_code == 429:
            print("Rate limited. Waiting 120 seconds...")
            time.sleep(120)
            continue

        response.raise_for_status()
        return response.json()

    raise Exception("Max retries exceeded")

# 3. Usage
tenant_id = "YOUR_TENANT_ID"
report_id = "YOUR_REPORT_ID"
client_id = "YOUR_CLIENT_ID"
client_secret = "YOUR_CLIENT_SECRET"
app_key = "YOUR_APP_KEY"

# Get MTD data
today = datetime.now()
from_date = today.replace(day=1).strftime("%Y-%m-%d")
to_date = today.strftime("%Y-%m-%d")

data = fetch_report(tenant_id, report_id, client_id, client_secret, app_key, from_date, to_date)
print(data)
